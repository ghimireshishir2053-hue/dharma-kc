## Removed — confirmed misattributed

**dudh-pokhari.jpg (Dudhpokhari palika) — deleted.** The Commons file "File:Dudh Pokhari Lake.jpg" was verified via its own description to depict **Gokyo Lake in Solukhumbu district** (Everest region), a completely different and more famous lake that happens to share the generic name "Dudh Pokhari" ("milk lake"). It is NOT Lamjung's Dudh Pokhari (the real pilgrimage lake near Himalchuli, ~4,560m, in Dudhpokhari Rural Municipality). No open-licensed photo of the actual Lamjung lake was found — the page now shows the branded placeholder instead of a wrong photo. The place description text was left as-is; it was independently verified accurate.
